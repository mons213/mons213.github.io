Screener Sync Desktop

A personal desktop utility for synchronizing a locally operated market screener between Windows and macOS.

Google Drive integration

The application uses Google authorization to save and retrieve screener database snapshots and synchronization metadata in the user's Google Drive. This allows the user to continue working on another computer. The market-data collector runs locally, not on this website.

The intended Google Drive permission is drive.file: access to files created by the application or explicitly selected or shared with it through supported Google authorization flows, rather than unrestricted access to every Drive file.

This website provides product information only. It does not host the screener, its databases, or an OAuth sign-in form.
