Privacy Policy

Screener Sync Desktop · Last updated: 6 October 2026

Purpose and information processed

Screener Sync Desktop is a personal, locally operated synchronization utility. It processes Google OAuth credentials, application-managed Drive file identifiers and metadata, database snapshots, and synchronization state to transfer the user's screener data between their computers. Snapshots may include market history, settings, comments, and manually recorded position information.

Google access and use

The Drive integration requests the drive.file scope to manage files created by the application or explicitly made accessible to it. Google user data is used only to provide synchronization, backup, recovery, and related integrity checks. It is not sold, used for advertising, or used to train generalized artificial intelligence or machine-learning models.

Screener Sync Desktop's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Storage and sharing

Application data and authorization tokens are stored on the user's computers. Synchronized files are stored in the user's Google Drive and transferred through Google's services. This informational website does not receive these files or tokens. Other people may gain access if the user shares their Drive files or devices. The application does not provide application data to advertisers or data brokers.

Retention, revocation and deletion

Data remains on the user's devices and Drive until removed by the user or the application's retention functions. The user can revoke Google access through Google Account connections. Revocation stops future authorized access but does not itself delete existing copies. To delete stored information, stop the application and remove its local data, stored credentials, and application-managed Drive files. Deletion of synchronized data can prevent recovery of history.

Security

Google API transfers use HTTPS. The user is responsible for protecting their devices and Drive account. No storage or transfer method is guaranteed against all failures or unauthorized access.

Website

These static pages contain no application-added analytics, advertising, or sign-in forms. Hosting is provided by GitHub Pages; the hosting provider may process technical request information under its own privacy policy.
